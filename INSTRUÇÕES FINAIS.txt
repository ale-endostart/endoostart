🔧 SE ALGO DER ERRO:
════════════════════════════════════════════════════════════════════════════

❌ "Port 3002 is in use"
   → Feche outras abas do navegador ou mude a porta em run-frontend.bat

❌ "ChunkLoadError" ou timeout
   → Feche os scripts (Ctrl+C)
   → Abra novamente (eles limpam cache automaticamente)

❌ "Cannot find module"
   → Abra PowerShell/CMD em C:\TurboOps\Code\frontend
   → Digite: npm install
   → Aguarde finalizar
   → Rode o script novamente

❌ Banco corrompido
   → Abra PowerShell em C:\TurboOps\Code\backend
   → Digite os comandos:
     cd C:\TurboOps\Code\backend
     rm dev.db
     rm -r prisma/migrations
     $env:DATABASE_URL="file:./dev.db"
     npx prisma migrate dev --name init
     npx prisma db seed


📊 VER DADOS DO BANCO:
════════════════════════════════════════════════════════════════════════════
